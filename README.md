# Canera

A low-cost, Arduino-based hand-safety system for sugarcane crushing machines.

**Status:** In progress

## Problem

Sugarcane crushing machines can cause serious hand-crushing injuries when a user's hand gets too close to the rollers. Safety systems for this exist, but many are expensive. Canera aims to be a low-cost alternative.

## How It Works

1. An IR sensor watches the area near the machine.
2. When a hand comes within a set distance, the Arduino detects it.
3. A buzzer sounds and an LED blinks to alert the user.
4. The machine is designed to stop automatically to prevent injury.

## Components

- Arduino
- IR sensor
- Buzzer
- LED
